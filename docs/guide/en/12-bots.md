# Agent Teams

ChemClaw Mobile uses the official DSH Agent Teams capability rather than the retired DS Bot group-chat entry. Open **Agent team** in All features, or [open it](dshgo://open/agent-team).

## Enable the plugin

Connect to your current host and open the team page. If the plugin is off, enable it there. If it is not installed, open **Settings › Plugins** and check the target host and its permissions. Some changes require an engine restart, which interrupts current work.

Remote hosts enforce their own installation and toggle permissions. Enabling a plugin on the phone does not enable it on every connected host.

## Create a task-specific team

Describe the task, expected output and any specialties in a conversation. Ask AI to use official Agent Teams tools when parallel work is justified. The number of teammates and their responsibilities should follow the actual workload, not a fixed roster.

The team page displays members, the shared task board and collaboration messages. Open or create a conversation first if there is no current session. Actual team operations depend on the connected DSH host and its permissions.

## Disable and recover

You may turn off the official Agent Teams plugin in Settings. It should stay off until you explicitly reenable it. If team creation fails, verify the current host, the plugin's state and the model's tool permissions before retrying.
